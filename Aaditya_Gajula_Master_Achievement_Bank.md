## How to use the evidence labels

| Label | Meaning |
|---|---|
| Verified record / offer / association | A university, testing organization, program or original correspondence directly supports the specific fact. Stored documents have not been authenticated with the issuer. |
| Verified public result / participation | A public competition/platform record supports the result or submission. |
| User-confirmed / user-reported | An explicit statement by Aaditya; employer/organizer proof may still be missing. |
| Artifact-supported / public team artifact | A project, paper or repository exists and supports its described scope. Performance and personal contribution may still need validation. |
| Résumé claim | Appears in a self-authored résumé without independent supporting record. |
| Needs confirmation / attribution unresolved | Keep in the bank as a lead; do not paste into a résumé yet. |

“Resume use: Yes” means the **conservative wording shown**, with its evidence status understood. It does not endorse every metric in the same entry. Optional entries belong mainly in targeted academic applications or the personal archive. Hold entries need more evidence.
